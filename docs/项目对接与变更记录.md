## 5. 导演台功能边界

导演台是 4.7.2 中的独立 3D 白模预演和镜头设计工具，主要负责：

- 场景物体、人物和道具摆放
- 人形骨骼姿态调整
- 相机机位和镜头快照
- 关键帧动画
- 运镜预览和视频导出
- 人物动作片段与场景路径联动

导演台功能修改原则：

1. 优先只修改 `DirectorStage3D.tsx` 及其直接相关类型或样式。
2. 不得把导演台动画循环、Three.js 场景对象或路径采样逻辑接入普通主画布渲染循环。
3. 不得修改用户数据目录格式，除非同时提供向后兼容和迁移说明。
4. 动画播放期间的计算必须有明确的播放状态边界，空闲状态不能持续做高成本采样。
5. 修改必须同时考虑桌面窗口尺寸、中文界面、键盘操作和导出流程。

### 2026-08-25 21:40：上下拖拽视口闪烁修复

- 需求来源：用户反馈上下拖动功能区域时 3D 画面闪烁。
- 修改文件：`E:\AIhuabu\JaceCanvas-dev-director\desktop-app\src\components\DirectorStage3D.tsx`、`E:\AIhuabu\项目对接与变更记录.md`
- 根因：每个 pointermove 都直接触发 React 布局更新，ResizeObserver 随后即使收到相同尺寸也重复调用 WebGL `renderer.setSize`，会反复清空和重建绘制缓冲。
- 修改内容：
  - 上下拖拽布局比例改为 requestAnimationFrame 节流，每个浏览器绘制帧最多提交一次状态更新。
  - 拖拽结束时提交最后一次比例，避免快速松开丢失最终位置。
  - ResizeObserver 缓存上一次视口宽高，尺寸不变时跳过 renderer 重置与相机投影更新。
- 数据/兼容性影响：不改变布局偏好、场景、路径、关键帧或输出数据；拖拽仍实时生效。
- 构建与验证：`desktop-app\npx tsc --noEmit`、`desktop-app\npm run build:web`、`desktop-app\node --check main.js` 通过；Electron 开发版已启动验证，主进程显示 JaceCanvas v4.7.2、GPU 加速已启用并开始启动后端服务。
