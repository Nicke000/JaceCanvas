## 4. 常用命令

在 `desktop-app` 目录执行：

```powershell

node --check main.js
```

在 `server` 目录执行：

```powershell

```


## 5. 导演台功能边界

导演台是 4.7.2 中的独立 3D 白模预演和镜头设计工具，主要负责：

- 场景物体、人物和道具摆放
- 人形骨骼姿态调整
- 相机机位和镜头快照
- 关键帧动画
- 运镜预览和视频导出
- 人物动作片段与场景路径联动

导演台功能修改原则：

1. 优先只修改 `DirectorStage3D.tsx` 及其直接相关类型或样式。
2. 不得把导演台动画循环、Three.js 场景对象或路径采样逻辑接入普通主画布渲染循环。
3. 不得修改用户数据目录格式，除非同时提供向后兼容和迁移说明。
4. 动画播放期间的计算必须有明确的播放状态边界，空闲状态不能持续做高成本采样。
5. 修改必须同时考虑桌面窗口尺寸、中文界面、键盘操作和导出流程。

## 7. 本次工作计划

本轮需求来自此前导演台功能讨论，目标是从干净 4.7.2 基线重新实现并验证：

1. 动作速度控制。
2. 循环开关。
3. 动作片段时长控制。
4. 角色沿场景路径持续移动。
5. 路径自动朝向，使角色沿运动方向转身。
6. 平滑路径支持，包括贝塞尔/平滑曲线语义。
7. 转向平滑，避免急转弯时瞬间改变角度。
8. 闭合路径循环时首尾连续，避免首尾跳变。

实现完成后必须补充第 8 节的变更记录，并列出实际验证结果。

### 2026-08-24 19:20：重新实现导演台角色路径与动作联动

- 需求来源：用户要求在干净的 GitHub 4.7.2 基线上继续此前导演台需求，包括动作速度、循环开关、动作片段时长、角色沿路径移动、自动朝向、平滑路径、转向平滑和闭环首尾连续。
- 修改文件：`desktop-app/src/components/DirectorStage3D.tsx`
- 修改内容：
  - 新增 `MotionPath` 数据结构，保存目标人物、控制点、路径时长、速度、循环、闭环、平滑、自动朝向和转向平滑参数。
  - 新增线性与 Catmull-Rom 风格路径采样；闭环路径使用首尾模运算，支持首尾连续采样。
  - 播放关键帧时，在根节点关键帧插值之后应用路径位置，避免路径位置被关键帧插值覆盖；人物骨骼仍由关键帧驱动。
  - 新增沿路径方向的自动朝向；使用水平切线和最短角差，结合转向平滑参数，避免跨越 `-PI/PI` 时反向长距离旋转。
  - 新增导演台“角色路径”控制行：选择人物、创建路径、速度、时长、循环、闭环、平滑、朝向、转向平滑和 JSON 控制点编辑。
  - 将路径配置写入 `director3d-prefs`，读取时对旧版缺少 `motionPaths` 的偏好保持兼容。
  - “新场地”操作会同步清空路径配置，避免旧人物路径残留到新场景。
- 行为影响：导演台播放至少两个关键帧时，已创建路径的人物会按路径持续移动；速度影响路径进度，时长决定完成一圈或一段所需时间，循环决定结束后是否回到起点继续，闭环决定是否连接最后点和第一点，平滑决定曲线采样，朝向决定是否沿切线转身。
- 数据/兼容性影响：仅扩展 `director3d-prefs` 的可选字段 `motionPaths`；旧偏好没有该字段时按空路径处理，不改变已有关键帧字段。路径控制点使用三维数组格式，例如 `[[0,0,0],[2,0,0]]`。
- 性能影响和风险：路径采样只在导演台关键帧播放状态存在时执行，不接入主画布；每帧只遍历已配置路径并查找对应对象。Catmull-Rom 可能在控制点急转时产生轻微 overshoot，使用时应检查地面和障碍物；本次未增加碰撞检测或地面吸附。
- 构建与验证：`desktop-app/npm run build:web` 通过；`desktop-app/node --check main.js` 通过；`desktop-app/git diff --check` 通过。构建仍有既有的 Vite CJS API、动态导入和大 chunk 警告，不是本次修改引入的编译错误。
- 已知限制：本轮只完成代码级构建验证，尚未通过交互界面实际创建人物、播放关键帧和录制视频验证；路径播放仍依赖至少两个关键帧，且非循环路径在关键帧时间轴循环时会按当前时间重新从路径起点采样。
